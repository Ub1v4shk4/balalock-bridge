# balalock-bridge

Техническая HTTPS-страница для загрузки публичной статистики Deadlock в мод balalock.

Страница выполняется во встроенном браузере игры. Запрашивает данные у api.deadlock-api.com и передаёт выбранные показатели в мод. Не хранит статистику, не использует аналитику или авторизацию Steam. Отдельная программа не нужна.

Рабочая страница: https://ub1v4shk4.github.io/balalock-bridge/v03.html
