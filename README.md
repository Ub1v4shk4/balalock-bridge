# Balagan Eye bridge

Статическая HTTPS-страница для автоматической загрузки публичной статистики Deadlock в Balagan Eye.

Работает во встроенном браузере игры. Не хранит статистику, не использует аналитику и не требует авторизации Steam или отдельной программы.

Текущая страница: https://ub1v4shk4.github.io/balalock-bridge/v05.html
